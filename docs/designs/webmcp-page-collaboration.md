# Design: First-party WebMCP collaboration on anc.dev

Generated by /office-hours on 2026-08-26 Branch: dev Repo: brettdavies/agentnative-site Status: APPROVED Mode: Builder

## Problem Statement

Headless agents already use `POST /mcp`. Browser agents (Gemini in Chrome, ChatGPT in-app browser, BrowserRun) still
scrape the HTML. Today's `src/client/webmcp.ts` only returns URLs (`get_principle_url`, `get_llms_index`,
`get_mcp_endpoint`) on spec pages. That is a directory, not a shared worksheet.

Build a first-party, page-scoped WebMCP layer so a co-browsing agent and a human share the live page: fill the audit
forms, then work the scorecard. Metered audits stay a human gesture (Turnstile). Do this in time for the OpenAI WebMCP
Challenge (submit by 3 Sep 2026, 1pm PT) on a URL judges can open.

## What Makes This Cool

The clip is not "agent filled a box." It is: prepare an audit of **anc.dev itself**, human clicks Audit, then the **same
agent on `/web/anc.dev`** reads failing rows and assembles a short fix prompt. The spec site is the worksheet for an
ingest-fix-reaudit loop. Code edits stay in the user's agent (Cursor/Codex). The site only re-prepares the next audit.
The MAY `webmcp` HTML-marker check is not a live `getTools` probe; the video must not claim it is.

## Constraints

- Interactive widgets never live in `content/*.md` (markdown twin / `llms-full.txt`).
- `execute()` never POSTs `/api/score`, never navigates to `/web/scoring`, never calls `getTurnstileToken`.
- Do not open CORS on `/mcp`. Do not flip Cloudflare Agent Readiness / inject `/.webmcp/bridge.js`.
- No-op only when both `document.modelContext` and `navigator.modelContext` are absent.
- PRODUCT.md: earn every element. Video-path status is `[data-web-audit-status]`. Do not use homepage
  `[data-live-score-status]` for Website prepare (it is `data-s="cli"` and hides).
- Judges: ChatGPT in-app browser or Chrome with `#enable-webmcp-testing`. Staging is behind Access. MIT license already
  in repo.
- Prefer `registerTool`. If only `provideContext` exists, fallback and log once. ChatGPT in-app and Chrome-with-flag are
  `registerTool`.

## Recommended Approach

Approach B, sequenced: video path green, then homepage CLI polish.

**Two Audit clicks (do not collapse):**

1. Homepage Website **Audit** = GET `/web-audit?url=` (`open_web_audit` when P1 ships). Not transact.
2. `/web-audit` **Audit** = Turnstile then `/web/scoring/<host>`. Only transact cut. Tools never fire it.

**3-minute sequence:** open `https://anc.dev/web-audit` → `fill_audit_url({url:"https://anc.dev"})` → `set_plan` writes
`[data-web-audit-status]` (`Agent prepared: audit anc.dev · waiting for you`) → human clicks Audit → `/web/anc.dev` →
`get_worksheet` → `assemble_fix_prompt({id})` for a named non-CORS check.

**Script attach:**

- Keep `/js/webmcp.js` on `/`, `/mcp`, `/p1`–`/p8`. Change `tests/agent-readiness-discovery.test.ts` in the same unit if
  those paths drop.
- `/web-audit`: concatenate `WEBMCP_SCRIPT` onto `extraScripts: ['/js/web-audit.js']`.
- `/web/<host>`: append `<script defer src="/js/webmcp.js">` in `buildWebSummaryBody` (used by `handleWebResultPage`).
  Do not touch `scoringBody` (`/web/scoring/<host>` / `web-audit-scoring.js`). Do not add it to
  `_internal/score-live-shell.html`.

**If homepage web fill ships:** add a `data-s="web"` status node in `06-homepage.mjs`. Not required for the canonical
demo.

**API:** Probe `document.modelContext || navigator.modelContext`. Prefer `registerTool`. `AbortSignal` on `pagehide` +
bfcache `pageshow`. `execute` returns a `DOMString` ≤1.5k. Names ≤30, descriptions ≤500. Schemas: `additionalProperties:
false`. Re-validate args. `untrustedContentHint` when output echoes a third-party target.

**Tool × page:**

| Tool                  | Kind                   | Pages                       | Input         | `execute` returns                                                                                                                            |
| --------------------- | ---------------------- | --------------------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `get_page_state`      | answer, `readOnlyHint` | `/`, `/web-audit`, `/web/*` | `{}`          | surface, url field, listing, path                                                                                                            |
| `fill_audit_url`      | act                    | `/web-audit`                | `{url}`       | confirmation; wrong page: error string                                                                                                       |
| `set_plan`            | act                    | `/web-audit`                | `{text}` ≤200 | `textContent` + `hidden = (text.length === 0)` on `[data-web-audit-status]` (same helper as `web-audit.ts`). Not a new widget                |
| `get_worksheet`       | answer, `readOnlyHint` | `/web/*`                    | `{}`          | `broken`/`absent` rows only (`id`, `keyword`, `status`). If still over 1.5k, truncate and suffix `… +N more`. Read `data-id` on `.web-check` |
| `assemble_fix_prompt` | act                    | `/web/*`                    | `{id}`        | truncated prompt or "see on-page widget" + id. Never click `[data-assemble-copy]`; clipboard is best-effort, not the success path            |
| `get_principle_url`   | answer                 | `/`, `/p*`, `/mcp`          | `{n}`         | URL string                                                                                                                                   |
| `get_llms_index`      | answer                 | `/`, `/p*`, `/mcp`          | `{}`          | URL string                                                                                                                                   |
| `get_mcp_endpoint`    | answer                 | `/`, `/p*`, `/mcp`          | `{}`          | endpoint + skill + server-card URLs                                                                                                          |

**P1 after video path:** `set_surface`, `fill_cli_target`, `fill_web_target`, `open_web_audit`, `set_public_listing`.
Wrong-page calls return an error string.

**Dogfood:** `fill_audit_url` with `https://anc.dev`. No extra `prepare_self_audit` unless it wraps that.

**Result DOM hook:** `renderCheck` in `src/worker/audit-web/summary-render.ts` must emit `data-id="${escHtml(row.id)}"`
on `.web-check`. `get_worksheet` and `assemble_fix_prompt` read that attribute. Skill URLs are not the id contract.

**Assemble clip:** never CORS (`mcp-cors-*`). If anc.dev has no MUST fails, use a named SHOULD/content-surface `id`, or
stop at `get_worksheet`.

**Not this week:** worker `webmcp` handler still greps markers.
